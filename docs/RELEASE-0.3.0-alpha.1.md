# HOSLauncher 0.3.0-alpha.1

首个公开测试版本（候选包，尚未发布）。

## 主要功能

- 一键启动网易 UU、Battle.net 和《风暴英雄》
- 冷启动最多一次 Windows UAC 确认
- UU 自动加速并进入系统托盘；热启动复用已经生效的加速状态
- Battle.net 已就绪时直接复用，冷启动窗口快速隐藏
- 自动启动《风暴英雄》，尝试隐藏游戏准备对话框
- 启动过程显示语义进度；Esc 可停止后续启动步骤，不关闭已经启动的程序
- 支持拖入网易 UU / 暴雪游戏平台快捷方式进行自动配置
- 自动发现并准备用户本机网易 UU 安装中的官方 CLI
- 免安装、自包含 x64 便携版，无需预装 .NET
- 设置、About / Safety（关于 / 安全）、本地日志和反馈入口

## 首次使用前

1. 已安装并登录网易 UU，确认加速服务可用。
2. 已安装并登录 Battle.net。
3. 已安装《风暴英雄》并完成更新。
4. UU 设置：关闭窗口时 → 隐藏到系统托盘。
5. Battle.net 设置：点击 X 时 → 最小化战网到系统栏。
6. 完整解压 ZIP，保留 `app` 文件夹，然后运行 `HOSLauncher.exe`。

## 已知限制

- Windows 10 x64 已有开发版本实机验证；此候选包仍需手动验收。
- Windows 11 x64 尚未实机验证。
- UU / Battle.net 启动时仍可能出现极短窗口闪烁，战网冷启动主窗口仍可能短暂出现。
- 当前不包含 UU / Battle.net 自动更新识别或多加速器支持。
- 当前没有正式 Authenticode 代码签名。
- 窗口管理依赖第三方程序当前行为，不能保证所有版本零闪烁或兼容。

## 安全边界

当前版本不注入 DLL、不使用 Hook、不读写游戏进程内存、不修改《风暴英雄》游戏文件、
不抓取、拦截或篡改游戏网络数据包、不模拟游戏内键鼠输入、不绕过 Windows UAC、
不创建常驻高权限服务、不读取或提取账号密码、Cookie、Token 等认证信息。

仅使用正常程序启动、本机官方 CLI 和 Windows 窗口管理接口；必要时通过标准 UAC
请求窄功能辅助程序权限。配置、CLI 缓存和日志保存在 `%LOCALAPPDATA%\StormHeroesLauncher`。
日志可能包含本地路径和诊断信息，分享前请检查私人信息。以上并非反作弊兼容或账号风险保证。
包内不分发网易 CLI、战网文件或开发者 Observer。
