# Neutral launcher icon

Original geometric artwork created specifically for StormHeroesLauncher: a pale application-window outline and a teal play triangle on a slate rounded square. No logos, stock images, fonts, system icons, or third-party artwork are included.

Generated offline by `tools/Generate-LauncherIcon.ps1` using System.Drawing. ICO contains 16, 24, 32, 48, 64 and 256 pixel 32-bit RGBA PNG frames. The preview is a source asset, not a separate published file.

The artwork may be used, modified and redistributed with this project. It introduces no third-party artwork licensing requirements.
